# 节点世界（Node World）

一个以 Canvas 绘制的节点探索游戏原型。山、森林、树、资源、地层、背包、身体和天空都以节点呈现：它们可以展开、收起、移动、采集、归类和放置。项目不依赖构建工具，直接打开 `index.html` 即可运行。

## 快速开始

1. 直接用浏览器打开 `index.html`。
2. 点击山、森林和树，逐层展开世界。
3. 点击屏幕底部的身体，打开手和嘴。
4. 点击手使它附着在鼠标上，再点击终端资源完成采集。
5. 在左侧工作区打开背包，整理、拆分或把物品放回地下替补层。

音频受浏览器自动播放策略影响时，首次点击画布后会开始背景音乐。

## 核心玩法

### 节点即世界

游戏的一切由节点构成。静态节点通常有子节点，左键可以展开或收起；终端节点是可采集的资源。节点之间的连线表达显示层面的隶属关系，而地下的替补层使用独立的隐藏链表达“当前节点被清空后，下一个节点顶上来”。

初始主结构大致为：

```text
山
└─ 森林
   ├─ 树 × N
   │  ├─ 树枝 → 花 / 种子
   │  ├─ 树干 → 原木 / 动态生物
   │  └─ 地下替补层 → 土 / 矿物 … → 基岩
   └─ 蘑菇等森林资源
```

节点的出现概率和一次出现数量都由 `js/config.js` 的 `NODE_TYPES` 控制。固定随机种子会让同一局游戏复现相同的随机结果。

### 地下替补层

树或矿物节点下方的 `?` 卡片不是普通子节点，而是尚未揭示的替补层：

- `?` 数量代表后续仍有多少层；它们不能被点击或拖出。
- 当前上层被完全采集后，下一层接替它的位置与父级关系。
- 地下层可包含土、铁矿、铜矿、金矿、钻石等；每种矿物又能展开成可采集的矿块。
- 每一条链的最后一层必定为基岩。基岩会晃动但永远不能被采集或移除。
- 放置物品会压入替补链最上方，而不是成为该层的普通子节点。

## 完整操作

| 操作 | 效果 |
| --- | --- |
| 左键静态节点 | 展开或收起分支。 |
| 左键终端世界节点 | 使其附着鼠标；再次左键放下。 |
| 右键 | 取消当前附着/工具操作，节点回到原处。 |
| 左键空白世界 | 取消当前普通选中。 |
| 框选 | 框选世界节点；选到父节点时移动会携带可见子树。 |
| 鼠标滚轮（世界） | 缩放世界视角。 |
| 中键拖动（世界） | 平移世界视角。 |
| 鼠标滚轮（工作区） | 缩放工作区内容，不影响世界。 |
| 中键拖动（工作区） | 平移工作区内容。 |
| Ctrl + 左键世界节点 / 分类 | 给节点改名，名称全局唯一。 |
| Ctrl + F | 聚焦搜索框；输入已命名节点名称后按 Enter 定位。 |
| 空格 + 左键 | 对携带的背包物品执行放置。 |

节点悬停时会显示名称；已经重命名的节点会显示新名称。

## 工作区、背包与分类

左侧是独立的工作区。它位于世界上方，拥有自己的缩放和平移，并保留右侧详情栏的空间。

### 工作区边框

- 点击 `<` 收起工作区；点击 `>` 恢复到上次宽度。
- 按住 `<` 或 `>` 横向拖动可以调整工作区宽度。
- 工作区最窄不会压住背包或思考节点，最宽不会遮挡右侧详情栏收起后的展开把手。
- 搜索分类节点时，只会在当前工作区范围内居中，不会强制铺满整个屏幕。

### 背包

采集完成的物品优先进入背包根节点。相同物品显示为一个带数量的数值节点，而非反复堆叠的卡片。

- 单击物品节点：拆出一件，并使其附着鼠标。
- 双击完整 pile：携带整个 pile，可按放置规则放入世界。
- 右下角数字框：输入数量并按 Enter，拆出对应数量；拆出的部分会轻微错位并与来源保持连线。
- 关闭背包或点击刷新时，尚未归类/放置的拆分物会自动合并回来源。
- 从背包拖到世界的节点会切换为世界节点大小；从世界进入工作区则切换为工作区大小。

### 分类节点

背包与每个自定义分类节点都带有 `+` / `−`：

- `+`：新建一层分类节点。
- `−`：删除该层最后创建的分类；其中物品与子分类会逐级上移到父分类。
- 每层分类数量受 `BACKPACK_CUSTOM_CONFIG.maxChildrenPerLayer` 控制，默认是 5。
- Ctrl + 左键分类：未携带物品时改名；携带背包物品或完整 pile 时，将该物品归入这个分类。
- 相同类型的物品在同一分类中会合并；不同分类中的同类物品保持各自独立数量。
- 分类中的完整 pile 也支持拆分、携带、归类和放置。

一件物品或一个 pile 一旦放到世界地下层，就被视为世界节点，不再保留背包分类来源。之后重新采集，会作为新资源进入背包根节点。

## 身体与生存

身体、背包、饥饿、生命和专注固定在屏幕下方，属于 UI。它们不会随世界相机缩放和平移。

### 手：采集

1. 点击身体展开手与嘴。
2. 点击手，让手附着于鼠标。
3. 点击可采集终端节点。每次点击增加进度，并只让目标节点轻微晃动。
4. 达到该节点配置的 `harvestClicks` 后，资源进入背包。

采集过程中切换到另一个目标，原目标的采集进度会归零。手每次采集都会损耗耐久；耐久归零后手永久失去。手会随时间缓慢恢复耐久。

### 嘴：进食

嘴只能对工作区/背包中的可食用物品生效，不能直接吃世界里的资源。食用会回复饥饿，食物和其来源 pile 会有晃动反馈。部分食物可设置中毒概率与伤害。

嘴同样有耐久，进食会损耗，闲置时会缓慢恢复；耐久归零后嘴永久失去。

### 饥饿、生命与专注

- 三项资源初始值与上限由 `RESOURCE_CONFIG` 设置，默认均为 10。
- 每次采集消耗目标节点配置的 `harvestHungerCost`，通常是小数。
- 饥饿不足时，缺额转而扣除生命。
- 饥饿已满且生命未满时，生命会缓慢恢复。
- 生命为 0 时游戏结束，使用“重新开始”开启新一局。

底部资源节点也可按数量拆出、移动并归位；数值运算会保留生命等资源的小数余量。

## 放置规则

携带背包物品时，按住空格再左键点击目标地层。一个目标可放置必须同时满足：

1. 该替补链最底部为基岩；
2. 从目标层向下的各层都是矿物/地层节点；
3. 被放置物品符合静态或动态节点的归属规则。

静态物品放入后成为最上层替补节点。动态物品（例如鸟、甲虫）放置时会检查目标静态父节点类型是否符合它在 `config.js` 中的原生父级类型：符合则成为新父级子节点；不符合则按动态节点的迁徙/消失规则处理。

## 命名与搜索

仅世界节点和自定义分类节点允许命名，UI、背包普通物品和资源节点不可命名。

- Ctrl + 左键一个可命名节点，输入新名称。
- 名称全局唯一，重复名称会被拒绝。
- Ctrl + F 自动选中搜索框；输入名称并按 Enter。
- 世界节点会自动展开它的祖先链、恢复世界缩放为初始大小，并居中显示。
- 分类节点会在工作区当前宽度中居中显示，工作区内容缩放恢复为 1。
- 搜索只负责定位，不会将节点标蓝或改变当前黏附状态。

## 时间与动态节点

天空在开局自动展开。白天显示太阳、黑夜显示月亮；二者随游戏时间从屏幕右侧移动至左侧。时间参数位于 `TIME_CONFIG`。

动态节点（当前包括鸟、甲虫）具有以下规则：

- 由各自的 `spawnChance` 与 `spawnCount` 决定出现概率和数量。
- 在父节点的可见后代范围内随机移动；当只剩一个静态同级节点时，使用配置的额外边距避免卡住。
- 动态节点不能独自留在静态父节点下；父级或同级静态支撑消失时，它会尝试迁徙到祖先范围内同类型父节点下。
- 找不到合适父节点时，动态节点消失。
- 动态节点在世界中不能被普通拖动，必须由手捕获后进入背包，再按放置规则安置。

## 配置新节点

`js/config.js` 是内容配置入口。新节点通常只需在 `NODE_TYPES` 添加一项，再按需要补充 `NODE_DESCRIPTIONS`。例如：

```js
蘑菇: {
  emoji: "🍄",
  children: [],
  spawnChance: 0.7,
  spawnCount: [1, 3],
  harvestClicks: 3,
  harvestHungerCost: .2,
  harvestWear: .6,
  edible: true,
  hungerRestore: 4,
  poisonChance: .2,
  poisonDamage: 2,
  sound: "mushroom.wav",
  volume: .65
}
```

常用字段：

| 字段 | 含义 |
| --- | --- |
| `emoji` | 节点卡片中显示的图标。 |
| `children` | 展开后可生成的子节点类型。 |
| `spawnChance` | 本类型在父节点展开时的出现概率，范围 0–1。 |
| `spawnCount` | 出现后的数量范围 `[最小, 最大]`，两端都包含。 |
| `harvestClicks` | 采集所需点击次数；没有该字段的普通静态节点不可采集。 |
| `harvestHungerCost` | 每次采集消耗的饥饿。 |
| `harvestWear` / `eatWear` | 采集/食用造成的手或嘴耐久损耗。 |
| `edible` / `hungerRestore` | 是否可食，以及回复多少饥饿。 |
| `poisonChance` / `poisonDamage` | 中毒概率与造成的伤害。 |
| `dynamic` | 动态节点运动参数：速度、转向间隔与单静态子节点时的活动边距。 |
| `hiddenLayer` / `groundLayer` | 是否是可出现于地下替补链的地层类型。 |
| `indestructible` | 是否不可采集；基岩使用该标记。 |
| `sound` / `volume` | `sounds/` 下的音频文件名，以及 0–1 的独立音量。 |

固定随机种子由 `RANDOM_SEED` 控制。保持同一个种子与相同的操作顺序，可复现同一局的随机生成。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | Canvas、搜索框、详情栏、重启按钮和数量输入框。 |
| `styles.css` | DOM 层 UI 的固定样式与层级。 |
| `js/config.js` | 节点类型、随机、音频、资源、时间、工作区等配置。 |
| `js/node.js` | 统一的 `Node` 状态模型。 |
| `js/world.js` | 世界树、替补链、背包数量、放置、身体、资源等核心规则。 |
| `js/dynamic.js` | 动态节点的移动、边界和迁徙。 |
| `js/time.js` / `js/celestial.js` | 游戏时钟、昼夜、太阳和月亮。 |
| `js/workspace-panel.js` | 左侧工作区的开合、宽度、缩放、平移与坐标转换。 |
| `js/renderer.js` | Canvas 绘制；不负责改变游戏规则。 |
| `js/interaction-core.js` | 事件注册、搜索、输入与公共交互状态。 |
| `js/interaction-world.js` | 世界点击、框选、命名与世界搜索定位。 |
| `js/interaction-ui.js` | 背包、分类、资源和 UI 交互。 |
| `js/interaction-tools.js` | 手、嘴、采集、进食与工具状态。 |
| `js/interaction-view.js` | 世界/工作区视角操作。 |
| `js/detail-panel.js` | 右侧节点详情与无选中时的世界指南。 |
| `js/audio.js` | 背景音乐、节点音效和 UI 音效。 |
| `tests/game-rules.test.js` | 关键规则的自动回归测试。 |

脚本以普通 `<script>` 顺序加载并通过 `window.TreeWorld` 共享模块，确保双击 `index.html` 的 `file://` 场景也能直接运行。


当前测试覆盖固定随机、生成概率和数量、替补层接替、放置、背包拆分/归位/分类、资源小数、身体工具、动态节点迁徙、天空昼夜、工作区、命名搜索及跨区域放置限制等关键回归规则。

## 音频资源

把音频文件放入 `sounds/`，并在相应节点配置中写入文件名和 `volume`。`volume` 的有效范围是 0 到 1；参数名是 `volume`，不是 `volumn`。

背景音乐由 `BACKGROUND_MUSIC` 配置，游戏启动后循环播放。浏览器需要用户手势时，首次点击画布会自动补启播放。
