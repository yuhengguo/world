# 节点世界开发日志与代码注释说明书

> 文档状态：2026-08-08
>
> 本文档只记录项目架构、规则和开发历史，不修改任何现有 JavaScript、HTML 或 CSS 代码。

## 1. 项目定位

这是一个以 Canvas 为画布的“节点世界”原型。世界中的树、树枝、资源、矿物、土层和基岩均为节点；节点可展开、收起、移动、采集或作为隐藏层逐层揭示。

项目刻意将“世界节点”和“屏幕 UI 节点”统一为同一个 `Node` 数据模型：它们视觉上相似，但坐标系与交互规则不同。

- 世界节点使用相机坐标，会受到缩放和平移影响。
- UI 节点使用屏幕坐标，不会随世界缩放移动。
- 隐藏层不进入可命中的世界节点列表，只绘制为问号卡片，避免被提前操作。

## 2. 文件职责

| 文件 | 职责 | 维护重点 |
| --- | --- | --- |
| `index.html` | 提供 Canvas、重新开始按钮、状态提示和数值拆分输入框 | 所有脚本保持普通脚本顺序加载，确保 `file://` 本地直接打开不黑屏。 |
| `styles.css` | 页面层 UI 的固定定位与样式 | Canvas 节点本身不在这里绘制；这里仅管理页面级按钮、提示和原生输入框。 |
| `js/config.js` | 唯一的内容配置入口 | 新增节点类型、emoji、子节点、采集次数、消耗、食用、中毒、磨损等优先在这里完成。 |
| `js/node.js` | `Node` 数据模型 | 只保存状态，不处理绘制或鼠标事件。 |
| `js/world.js` | 世界规则和数据状态 | 节点展开/消失、隐藏层、背包、资源、身体工具、耐久和生命规则均在这里。 |
| `js/renderer.js` | Canvas 渲染 | 只读取状态并绘制，原则上不修改游戏数据。 |
| `js/interaction.js` | 鼠标、滚轮、框选、拖放、采集、进食等输入分发 | 负责将用户操作转换成对 `World` 的规则调用。 |
| `js/audio.js` | 音效播放入口 | 音效文件名由配置表或 UI 音效表控制。 |
| `js/ui.js` | 背包开关状态与顶部状态提示 | 不保存世界资源或库存的真实数据。 |
| `js/main.js` | 应用入口与渲染循环 | 创建模块、处理窗口尺寸、绑定刷新节点逻辑、驱动每帧更新。 |

## 3. 数据模型说明

### 3.1 Node 的通用字段

`js/node.js` 中的 `Node` 是所有节点的统一结构。关键字段如下：

| 字段 | 含义 |
| --- | --- |
| `type` | 节点类型，例如“树”“种子”“背包”“饥饿”。 |
| `x` / `y` | 节点中心坐标；世界节点是世界坐标，UI 节点是屏幕坐标。 |
| `ui` | `true` 表示该节点属于屏幕 UI。 |
| `children` | 常规父子结构，例如树的枝干、身体的手和嘴。 |
| `underlays` | 叠在节点下方但尚未出现的隐藏层，不属于普通 `children`。 |
| `visible` / `open` | 是否可见、是否处于展开状态。 |
| `selected` | 是否被选中，用于蓝色描边和批量移动。 |
| `harvestProgress` | 当前采集进度。 |
| `shakeUntil` | 节点震动效果的截止时间。 |
| `locked` | 隐藏层锁定标记；锁定时不可被鼠标命中。 |
| `edible` | 是否可以被嘴吃掉。 |
| `poisoned` | 当前实例是否已随机判定为中毒物品。 |
| `durability` / `lost` | 手、嘴等工具的耐久及永久损坏状态。 |

### 3.2 三种数量来源

数量相关逻辑必须遵守“一个权威来源”原则，避免重复累计。

1. 世界采集物：完成采集后写入 `world.inventory[type]`。
2. 背包数值节点：仅是 `world.inventory` 的可视化；拆出节点不改变库存总数。
3. 饥饿、生命、专注：真实数值保存在 `world.resources[type]`；底部原节点和临时拆分节点只负责显示与交互。

背包与资源的“回收”均不能简单执行 `+1`。正确方式是依据权威总值减去当前仍在外部的拆分数量，重新计算原节点显示值。这是防止数量重复增加的核心约束。

## 4. 世界结构与隐藏层

### 4.1 树的常规结构

默认世界从树根节点开始。树展开后可生成树枝、树干；树枝可生成花或种子；树干可生成原木。只有终端节点可采集。

终端节点判断条件：

- 不是 UI；
- 不是基岩；
- 没有已生成的子节点；
- 配置中没有可继续展开的子节点类型。

### 4.2 隐藏层结构

树和土层下方使用 `underlays` 建立单链隐藏层。它们不是普通父子节点，目的是表达“叠在下方、尚未挖到”的层。

- 未出现的隐藏层绘制为带问号的卡片。
- 隐藏卡片不可拖动、不可点击。
- 前一层被清空后，只揭示下一层。
- 隐藏层可随机出现土、铁矿、铜矿、金矿、钻石。
- 每条隐藏层的最后一层固定为基岩。
- 基岩不可采集、不可消失；触碰时只震动。

## 5. 采集、饥饿、生命与游戏结束

### 5.1 手的采集流程

1. 点击身体展开工具。
2. 点击手，手附着于鼠标。
3. 点击世界终端节点，增加该节点采集进度并播放对应音效。
4. 点击不同目标时，前一个未完成目标的进度归零。
5. 达到节点配置的 `harvestClicks` 后，节点进入背包。

采集仅震动被采集的终端节点。不可采集节点不会被删除。

### 5.2 饥饿和生命

- 每次成功采集消耗配置中的 `harvestHungerCost`。
- 饥饿不足时，缺少部分转而扣除生命。
- 生命归零后进入游戏结束状态，显示“重新开始”。
- 饥饿满值且生命未满时，生命会逐步恢复。
- 当前饥饿、生命、专注初始值均为 10。

### 5.3 嘴与食物

- 嘴只对背包节点中的可食用物品响应。
- 嘴点到世界中的种子、花或任何其他世界节点时必须没有反应；不得带起或附着世界节点。
- 花和种子可在配置中设置饥饿回复、中毒概率和中毒伤害。
- 吃掉物品后减少背包权威库存，并更新底部资源显示。

## 6. 背包数值节点

背包展开后，每个物品类型只显示为一个节点，而不是重复绘制多张卡片。

### 6.1 视觉约定

- 节点左下角显示 `×数量`。
- 节点底部有数量滑条。
- 节点左下方还有原生数字输入框，可直接输入本次要拆出的数量。
- 背包节点与物品节点用线连接。
- 被拆出的节点与来源数值节点用线连接。

### 6.2 拆分与回收约定

- 背包库存是唯一真实总数。
- 拆分只把原背包数值节点的一部分显示为独立节点，不改变库存总数。
- 右键取消、放回来源附近、关闭背包、使用刷新节点时，临时拆分节点应回归。
- 已拆出物品双击时必须无条件归回原背包节点。
- 双击未拆出的背包物品会选中同类整体，下一次拖动应作为整体移动而非再次拆分。

## 7. 底部资源数值节点

饥饿、生命、专注采用与背包相近的数值节点样式，但真实总值来自 `world.resources`。

- 原资源节点固定在底部栏，属于 UI。
- 可从原节点拆出临时资源节点，并保留来源连线。
- 最小拆分数量为 1，原节点至少保留 1。
- 回收时必须调用重新计算逻辑，不能对原节点直接累加。
- 双击资源节点会收回该资源的所有临时拆分节点。

## 8. 身体、工具和耐久

### 8.1 身体

- 身体固定在底部四节点栏，不能拖动。
- 身体、饥饿、生命、专注按等距整体居中。
- 点击身体的切换只能执行一次；鼠标按下和随后的 click 不能各切换一次，否则会出现“刚打开又关闭”的问题。

### 8.2 手与嘴

- 身体打开时，手与嘴在身体上方左右错开出现。
- 手和嘴通过连线连接回身体。
- 右键可让附着光标的手或嘴回到其在身体上方的初始位置。
- 手用于采集，嘴用于进食。

### 8.3 耐久

- 手在采集时消耗耐久。
- 嘴在进食时消耗耐久。
- 不同矿物、资源或食物可在配置中设置不同磨损。
- 未损坏的手和嘴会按 `durabilityRecovery` 随时间缓慢恢复。
- 耐久归零后，节点永久消失；自动恢复不应让已损坏节点复活。

## 9. 固定 UI 节点

### 9.1 刷新节点

左上角的 🔄 是 Canvas 节点，不是 HTML 按钮。

- 固定在屏幕左上角，不受缩放和平移影响。
- 悬停标签为“刷新”。
- 点击效果：收起最深展开层、关闭背包、回收临时背包节点、将可复原 UI 还原到初始化位置。

### 9.2 背包与思考节点

- 背包可打开或收起库存数值节点。
- 💡 思考节点仅在空间上位于背包上方。
- 思考节点不是背包子节点，不应写入 `backpack.children`，也不应被背包开关逻辑删除。

## 10. 鼠标规则

| 操作 | 结果 |
| --- | --- |
| 左键空白处 | 取消世界节点选择，或开始世界框选。 |
| 左键世界父节点 | 选中/展开/收起，拖动时移动其分支。 |
| 左键世界终端节点 | 第一次黏附光标，第二次放置，右键取消。 |
| 左键手 | 手跟随鼠标进入采集模式。 |
| 左键嘴 | 嘴跟随鼠标进入进食模式。 |
| 右键手/嘴 | 回到身体上方的工具位置。 |
| 左键背包数值节点 | 依据滑条或输入数量拆出节点。 |
| 左键资源数值节点 | 依据滑条或输入数量拆出资源节点。 |
| 双击背包物品 | 收回拆出物品，或选中同类节点整体。 |
| 双击资源节点 | 收回该资源的全部临时拆分节点。 |
| 滚轮 | 缩放世界相机。 |
| 中键拖动 | 平移世界相机。 |

## 11. 配置维护指南

新增一个常规节点类型时，优先只修改 `js/config.js` 的 `NODE_TYPES`：

```js
新节点: {
  emoji: "🧩",
  children: [],
  harvestClicks: 4,
  harvestHungerCost: .3,
  harvestWear: 1,
  edible: false,
  sound: "new-node.wav"
}
```

常用配置字段：

| 字段 | 用途 |
| --- | --- |
| `emoji` | 节点图标。 |
| `children` | 点击展开后可随机生成的子节点类型。空数组表示终端类型候选。 |
| `harvestClicks` | 采集所需点击次数。 |
| `harvestHungerCost` | 单次采集的饥饿消耗。 |
| `harvestWear` | 用手采集此节点时的手部磨损。 |
| `edible` / `hungerRestore` | 是否可食用及回复量。 |
| `eatWear` | 吃该食物时的嘴部磨损。 |
| `poisonChance` / `poisonDamage` | 中毒概率和生命伤害。 |
| `hiddenLayer` | 是否可随机作为隐藏层类型。 |
| `indestructible` | 是否不可采集，例如基岩。 |
| `durability` | 工具初始耐久。 |
| `durabilityRecovery` | 工具每秒耐久恢复量。 |

## 12. 关键问题与处理记录

### 12.1 本地打开黑屏

项目曾因 ES Module 加载方式在 `file://` 环境下不稳定而出现黑屏。当前采用普通脚本、按依赖顺序加载，保证双击 `index.html` 可运行。

### 12.2 采集进度无法完成

采集状态已收敛到终端节点自身：进度、震动和完成删除均只作用于目标节点。切换目标会清空前一目标进度。

### 12.3 隐藏层被提前拖出

隐藏层未加入正常可交互节点列表，并使用 `locked` 和问号绘制规则隔离，因此必须先清空上一层才能出现下一层。

### 12.4 工具与底部节点互相遮挡

底部节点采用等距分布；手、嘴上移展开。固定 UI 的一次点击会吞掉后续 click，避免身体展开后立刻再次收起。

### 12.5 背包和资源的数量重复增加

背包和资源都改为“权威总数 + 临时拆分显示”的模型：

- 背包回收从 `inventory[type]` 与剩余拆分量重新计算。
- 资源回收从 `resources[type]` 与剩余拆分量重新计算。

以后修改拆分逻辑时，必须保留这一约束，不能在回收函数中盲目执行 `quantity += amount`。

### 12.6 嘴错误黏附世界种子

嘴模式下，鼠标按下事件必须在进入世界终端节点拖动逻辑之前提前返回。嘴仅允许在点击事件中查找可食用的背包节点。

## 13. 验证清单

每次修改后，建议至少检查：

- 页面刷新后是否正常渲染，无黑屏。
- 点击身体是否只展开一次，手和嘴是否出现在上方。
- 用嘴点击世界种子是否保持无反应。
- 采集节点是否只震动目标终端节点。
- 背包拆出、归回、双击归回后，数量是否与采集总数一致。
- 资源拆出、归回、双击收起后，数量是否与 `world.resources` 一致。
- 刷新节点是否关闭背包并收回临时背包节点。
- 手嘴耐久是否减少、缓慢恢复，并在归零后不再出现。

## 14. 后续建议

后续如继续扩展“节点世界”，建议优先保持以下边界：

1. 所有新节点内容优先放进 `config.js`。
2. 所有真实数量只保存在一个权威字段，UI 节点只做投影。
3. `renderer.js` 不写入游戏状态。
4. 世界规则放在 `world.js`，鼠标流程放在 `interaction.js`。
5. 修改 UI 节点位置时，同时检查 `mousedown` 与 `click` 是否会重复执行同一行为。
